# 发售前更新核对

游戏未发售时，本站不靠每天找新闻活着。做法是：盯住官方源头，有变化就改对应旧页，首页只挂一件正在发生的事。

本文件服从 CONTENT_ARCHITECTURE.md。没有足够官方材料时，不新开页面。

## 1. 每周核对的官方地址

平时每周看两次。遇到 Nintendo Direct、官方预告、新测试或商店页大改，当场看。

| 频率 | 地址 | 看什么 | 没变化时 |
| --- | --- | --- | --- |
| 每周两次 | [任天堂美国产品页](https://www.nintendo.com/us/store/products/the-duskbloods-switch-2/) | 发售窗口、平台、人数、会员、简介措辞、官方图 | 记下核对日，不改正文 |
| 每周两次 | [官方网络测试页（美国英语）](https://campaign.theduskbloods.jp/p/event/networktest/?region=the_americas&locate=US&lang=en) | 场次、报名、地区、官方对测试的新说明 | 首页 Now 可维持「测试已结束」 |
| 每周两次 | [官方网络测试玩法指南](https://campaign.theduskbloods.jp/p/event/networktest/gameplayguide/?region=the_americas&locate=US&lang=en) | 规则、角色名、武器、Kin、Virtue、联盟、印记 | 测试规则继续标成 Test-build only |
| 每周一次 | [FromSoftware 首发新闻稿](https://www.fromsoftware.jp/ww/pressrelease/20250402_theduskbloods_debut.html) | 是否被更新或被新稿取代 | 旧稿仍作来源，不删 |
| 每周一次 | [任天堂美国支持：测试报名错误](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71792/~/error-received-while-applying-to-the-duskbloods-network-test) | 新的错误码、登录、连接说明 | 错误页维持「官方只确认了报名链接错误」 |
| 有 Direct / 预告时 | [任天堂美国新闻](https://www.nintendo.com/us/whatsnew/) | 是否点名 The Duskbloods、新片、新日期 | 没点名就不写 |
| 有 Direct / 预告时 | FromSoftware 与 Nintendo of America 官方账号 | 原帖、官方片、官方图 | 转发和猜测不算确认 |

第二等只在官方页当天没有原文、但媒体明确引用任天堂或 FromSoftware 时才看。例如 Eurogamer、Video Games Chronicle。引用进站时必须带出处，标题不当成 Confirmed。

不列入每周清单：泄露、数据矿、内幕号、竞品 wiki 上的无来源表、倒计时站。

核对后至少做三件事：更新该页的核对日期；若事实变了，写进该页 change log；若这是当前最重要的一件事，改首页 Now，并写明下一次该看的时间。

## 2. 哪类消息改哪一页

| 消息 | 改哪一页 | 标签 | 首页 Now | 新开页吗 |
| --- | --- | --- | --- | --- |
| 商店页仍写 2026，没有更精确日期 | 发售日期 /release-date/ | Confirmed | 通常不改 | 否 |
| 任天堂否认某个具体日期 | 发售日期 /release-date/ | Confirmed（否认本身） | 可以挂一天 | 否 |
| 官方公布月或日 | 发售日期 /release-date/，首页标题视情况微调 | Confirmed | 要改 | 否 |
| 新测试场次、报名、结束说明 | 网络测试 /network-test/ | Confirmed | 要改 | 否 |
| 官方承认登录或服务器故障 | 登录错误 /network-test/errors/，必要时同步测试页 | Confirmed | 故障进行中才挂首页 | 否 |
| 玩家大量报告、官方未承认 | 登录错误页或现有页的「仍未知」 | Player-reported | 不进标题 | 否 |
| 玩法指南改了阶段、淘汰、最终三人 | 玩法 /gameplay/ | Test-build only，直到零售指南出现 | 大改才挂 | 否 |
| 官方新增或改 Bloodsworn 名字 | 角色 /characters/ | 测试名单标 Test-build only | 通常不改 | 否 |
| 官方武器、强化、血之力量变化 | 武器 /weapons-and-powers/ | Test-build only | 通常不改 | 否 |
| Kin 数量、召唤圈变化 | Kin /kin/ | Test-build only | 通常不改 | 否 |
| Virtue、联盟、印记规则变化 | 系统 /systems/ | Test-build only | 通常不改 | 否 |
| 独占、NSO、人数、单人说明变化 | Switch 2 /switch-2/ | Confirmed | 大改才挂 | 否 |
| 新官方静帧 | 用在已经存在的主题页，并写 Official still via Nintendo of America | 图是展示，不是新事实 | 否 | 否，不做图库页 |
| Nintendo Direct 预告片 | 先改被片中确认的那一页；片本身可作来源 | 片中原话才是 Confirmed | 可以挂 | 否 |
| 泄露、数据矿、单一爆料 | 默认不写。若必须提到，放进「仍未知」 | Unconfirmed | 不挂 | 否 |
| Boss 名、全地图、最强榜、倒计时 | 不写 | 无 | 不挂 | 否，资料不够前继续不做 |

只有同时满足下面两条，才考虑新地址：出现了现有页面盖不住的新搜索意图；官方材料够写完整一页。否则合并进上表对应页。

需求文档里的 /updates/ 以后可以做「官方事实变动日志」，现在用各页 change log 就够。
