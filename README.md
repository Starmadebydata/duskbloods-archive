# Duskbloods Archive

Unofficial English guide to The Duskbloods for US players.

Preview (not a custom domain): https://duskbloods-archive.aifeefee70.workers.dev/

The first edition has ten complete guides, source labels, official Nintendo stills, and a current-status desk for the network test.

## Local commands

- `npm test` checks required pages and source fields.
- `npm run dev` runs the local site.
- `npm run build` builds production files.
- `npm run preview` previews the Cloudflare-style build.

## Notes

- The site is unofficial. Nintendo and FromSoftware remain the sources of truth.
- Game images on the site are official stills hosted locally and captioned.
- A custom domain has not been connected yet.
